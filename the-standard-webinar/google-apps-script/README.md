# Google Sheets 등록 연동

이 스크립트는 The Standard 웨비나 폼의 이름, 회사, 부서, 직책, 이메일, 휴대폰 번호와 개인정보 동의 여부를 `Registrations` 시트에 저장합니다.

## 1. 스프레드시트와 스크립트 만들기

1. 등록 정보를 받을 새 Google 스프레드시트를 만듭니다.
2. `확장 프로그램 > Apps Script`를 엽니다.
3. 기본 `Code.gs` 내용을 [Code.gs](./Code.gs) 전체로 교체하고 저장합니다.

## 2. 웹 앱으로 배포하기

1. Apps Script 편집기에서 `배포 > 새 배포`를 누릅니다.
2. 유형에서 `웹 앱`을 선택합니다.
3. 다음을 설정합니다.
   - 실행: **나**
   - 액세스 권한: 로그인하지 않은 사용자를 포함한 **모든 사용자**
4. `배포`를 누르고 Google 권한 요청을 승인합니다.
5. 생성된 `https://script.google.com/macros/s/.../exec` URL을 복사합니다. `/dev` URL은 편집자만 테스트할 수 있으므로 실제 사이트에는 `/exec` URL을 사용합니다.

## 3. 배포 환경변수 연결하기

로컬에서는 프로젝트 루트의 `.env.local`에 아래처럼 입력합니다.

```bash
NEXT_PUBLIC_THE_STANDARD_GAS_WEB_APP_URL=https://script.google.com/macros/s/DEPLOYMENT_ID/exec
```

배포 서비스에서도 같은 이름의 환경변수를 추가한 뒤 **새로 배포**해야 합니다. `NEXT_PUBLIC_` 변수는 빌드 시 브라우저 코드에 포함되므로, 이 URL에는 비밀번호나 비밀값을 넣지 마세요.

## 4. 테스트 및 수정 후 재배포

- `/exec` URL을 브라우저에서 열어 상태 JSON이 표시되면 웹 앱이 준비된 것입니다.
- 실제 등록 폼을 한 번 제출한 뒤, 스프레드시트에 `Registrations` 시트와 새 행이 생성됐는지 확인합니다.
- 스크립트를 수정했다면 `배포 > 배포 관리 > 수정 > 새 버전 > 배포`로 다시 배포합니다. 기존 배포를 수정하면 URL은 유지됩니다.

## 보안 및 운영 유의사항

- 이메일과 휴대폰 번호는 개인정보입니다. 스프레드시트의 공유 권한은 운영자에게만 제한하세요.
- 공개 웹 앱 URL은 브라우저에 노출됩니다. 간단한 형식 검증만으로는 자동 등록을 완전히 막을 수 없으므로, 대규모 공개 캠페인에서는 서버 측 API·CAPTCHA·레이트 리밋을 추가하는 것을 권장합니다.
- Apps Script의 할당량과 동시 실행 제한이 있으므로, 트래픽이 매우 큰 행사에는 전용 백엔드나 폼 서비스를 검토하세요.
